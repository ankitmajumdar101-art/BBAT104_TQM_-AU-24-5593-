# Restaurant Billing System - User Manual



## 1. Introduction



The Restaurant Billing System is a desktop application developed to manage restaurant billing-related operations.



The system also includes reliability features developed according to the TQM quality objective:



**Q01: Improve Reliability**



\---



## 2. System Users



The system supports two user roles:



### Admin



The Admin can access:



\- Billing

\- Bill History

\- Menu Management

\- User Management

\- Audit Logs

\- Backup



### Cashier



The Cashier can access:



\- Billing

\- Bill History

\- Menu Management



Administrative functions are restricted from Cashier users.
